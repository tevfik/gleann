# gleann v1.8.13

A maintenance release. It contains everything in v1.8.12, plus a fix that makes the CI lint
job pass again. Nothing changes in behaviour, configuration or index format. Upgrading from
v1.8.12 is optional.

## Fixed

- The TUI settings screen had an unused field. `staticcheck` reported it (U1000), and the
  `Lint & Vuln Scan` job of the v1.8.12 commit failed on it. The field is removed.

## Notes

- v1.8.12 was published twice under the same tag. Both builds report the version
  `v1.8.12`, so `gleann update` cannot tell them apart. This release has a new version
  number, so `gleann update` installs it on every machine that runs either v1.8.12 build.
- For what v1.8.12 added, see [v1.8.12.md](v1.8.12.md): one settings list for the web UI and
  the TUI, reranker settings and recommended models, in-process reranking with bitllm.c,
  and llama.cpp b12176.
