# gleann v1.22.0

A feature and hardening release. The server's watch now syncs the index (it
used to count changed files and do nothing), memory scopes keep same-named
directories apart, memory export and import are scoped and previewable, and
`gleann search` and `gleann ask` take `--filter`. A first run without Ollama
informs and guides instead of downloading in the background; automatic
downloads are an explicit opt-in (`llamacpp_config.auto_download`).
EmbeddingGemma-2 is an opt-in catalogue model with its prompt prefixes.
`OLLAMA_HOST` is honoured by every command, and `memory forget` and `memory
clear` can no longer delete more than the command line says. Many Windows and
macOS path and locking defects are fixed.

**Highlights**

- **Real server-side watch sync.** `POST /api/indexes/{name}/watch`,
  `auto_watch` and `GLEANN_AUTO_INDEX_DIRS` sync the exact changed paths and
  invalidate the cached searcher, so the next search sees the update. One task
  per index; while another process holds `<name>.lock` it retries with
  back-off (5 s, doubling up to 5 min).
- **Memory scopes keep same-named directories apart (H7).** A repository
  without an origin remote gets `local:<name>-<8-hex-path-hash>`, a plain
  directory `dir:<name>-<8-hex-path-hash>`; a symlinked directory shares the
  scope of its target.
- **Scoped `memory export --scope <s>|all` and `memory import --dry-run`.**
  Export records a manifest and prunes only its own generated files.
- **`--filter 'field op value'` on `gleann search` and `gleann ask`.**
  Repeatable; operators `eq`, `ne`, `gt`, `gte`, `lt`, `lte`, `in`, `nin`,
  `contains`, `startswith`, `endswith` and `exists`.
- **First run without Ollama.** No model is downloaded in the background;
  `gleann serve`, `setup --bootstrap` and `setup --auto` print guidance.
  `llamacpp_config.auto_download: true` opts in to a foreground download.
- **EmbeddingGemma-2 (Q8_0) as an opt-in model.** `gleann models download
  embeddinggemma-2` (310 MB, 768 dimensions). Never a default.
- **`OLLAMA_HOST` is honoured everywhere**, with one rule: flag, then
  `OLLAMA_HOST`, then saved config, then default.
- **Safer `memory forget` and `memory clear`.**

Also new: `gleann graph stats`, a graph provenance record, `memory reflect
--list`, and `one_per_file` on REST and MCP search.

## Breaking / behaviour changes

Read these before upgrading a server or a script.

- **`OLLAMA_HOST` now beats a saved `ollama_host`.** Precedence is `--host`,
  `OLLAMA_HOST`, saved config, default. Unset `OLLAMA_HOST` (or point it at the
  same server) if you relied on the saved host winning. A value without a
  scheme means `http` and port 11434; `0.0.0.0` and `::` connect to
  `127.0.0.1` and `[::1]`.
- **`gleann serve` never pulls models.** With a reachable Ollama that lacks
  the configured models it prints what is missing and the commands to run
  (`ollama pull`, `gleann models download`, `gleann setup --auto`).
- **`setup --auto` pulls only after a typed `y` or `yes`, or `--yes`.** End of
  input, an empty line or no terminal mean no (exit 1, nothing saved or
  downloaded).
- **`gleann memory list` defaults to the detected repository scope plus
  global.** `--scope all` (or `*`) restores the full listing; `--scope <name>`
  lists one scope.
- **`gleann memory export` skips short-term and expired blocks.**
  `--include-short` and `--include-expired` restore the full dump.
- **`memory forget` refuses a content match of more than one block without
  `--all`.** Nothing is deleted and the matches are listed: the CLI exits 2,
  `DELETE /api/blocks/{id}` answers 409 with `matches`, MCP `memory_forget`
  returns a tool error. Use `--all`, `?all=true` or `"all": true` to delete
  them all.
- **`memory clear` exits 2 on a malformed form** (`--tier` without a value, an
  unknown tier or option, two tiers) and deletes nothing. A bare `memory clear`
  still clears every tier.
- **An ID prefix for `forget` needs 8 or more hex characters.** `forget 2024`
  is a content search. An argument matching both an ID prefix and block
  content is refused.
- **`POST /api/indexes/{name}/watch` without `enable` returns 400.** It used
  to mean false and switched the watch off.
- **A REST `exists` filter without `value` means true** (it used to match
  passages without the field). A non-boolean value is a 400.
- **`ext exists` ignores empty extensions**, and `ext` filter values compare
  lower-cased.
- **`memory reflect --limit` or `--json` without `--list`, and a bad `--limit`
  value, exit 2.**
- **`memory <subcommand> --help` prints usage and exits 0** instead of reaching
  the subcommand as query text.
- **`--filter` is strict.** A missing value, an empty `--filter=`, a trailing
  `--filter` and an upper-case operator exit 2.
- **Memory export file names** use only `[A-Za-z0-9._-]`; files written by
  earlier versions with other characters are no longer pruned automatically.

No setting is removed. `setup_notice` in `config.json` is written when
Ollama is unreachable and removed once Ollama answers or the configured local
model is installed.

## Upgrade notes

- **The H7 scope migration runs automatically and is non-destructive.** It
  records the bare scope names that already exist, so pre-v1.22 blocks stay
  readable from the matching prefixed scope; new writes use the collision-safe
  scope. No block is rewritten or deleted.
- **Blocks of a plain directory opened through a symlink with a different
  name** are no longer shown by default, because the scope now carries the
  resolved target name. They are not deleted: `--scope all` or `--scope
  <old-name>` still shows them. Git repositories are unaffected.
- **Gemma indexes built before this release stay unprefixed until rebuilt.**
  Models whose id or file name contains `embeddinggemma` get `title: none |
  text: ` before passages and `task: search result | query: ` before queries;
  the prefixes are recorded in the index metadata and are part of the
  embedding cache key. Rebuild an existing EmbeddingGemma index to get them.
- **EmbeddingGemma-2 needs `embedding_provider: "eif"`.** The `llamacpp`
  provider refuses it with an error (llama-server cannot load it);
  EmbeddingGemma v1 files still work there.
- **A catalogue id in `embedding_model`** (including the first-run default
  `bge-m3`) is resolved to the installed file at run time; the config file is
  not rewritten.
- **A graph written by an older gleann** is reported by `gleann graph stats`,
  `gleann index info` and `gleann doctor`, which name `gleann graph build
  <name>`. Graph rows are never migrated on their own.
- **Windows.**
  - Memory export pruning refuses directory junctions and reparse points, and
    a refused prune prints one warning with the first skipped path.
  - Scope paths are canonical: 8.3 short names are expanded, and the path is
    lower-cased with `/` separators. A pre-v1.22 bare scope name matches
    case-insensitively.
  - Export names containing `:` (an NTFS stream marker) become `_`.
  - Windows is exercised through CI.
- **macOS.** `/var` and `/private/var` give one scope; case is not folded.

## Added

- EmbeddingGemma-2 catalogue model and prompt prefixes (see above).
- `gleann graph stats --index <name> [--json]` and MCP `gleann_graph_stats`:
  row counts plus the provenance record (extractor version, resolver and
  reason, tree-sitter, built at, dirty files, edges by confidence).
- `gleann memory reflect --list [--limit N] [--json]` lists stored reflection
  runs without an LLM.
- `one_per_file` on `POST /api/indexes/{name}/search`, `POST /api/search` and
  the MCP `gleann_search`, `gleann_search_multi` and `gleann_search_ids`.
- `gleann memory export --scope <s>|all` with a manifest
  (`.gleann-export-manifest.json`) that prunes forgotten blocks' files.
- `gleann memory import --dry-run`; preview and import name hand-edited export
  files whose `updated_at` did not move forward.
- `--filter` on `gleann search` and `gleann ask`, documented in
  `docs/configuration.md`.

## Security

- **Export pruning is confined to its own files.** A manifest entry is
  deleted only when it has the generated `<name>-<8hex>.md` shape, is a
  regular file, and no component below the export root is a symlink, so a
  hand-edited manifest cannot delete anything else.
- **Junctions and reparse points** on Windows can no longer lead a prune
  outside the export directory.
- **`memory forget` and `memory clear` cannot delete by accident:** see the
  behaviour changes above. `memory forget --help` no longer deletes every block
  containing `--help`.

## Fixes

**Memory**

- Same-named directories no longer share memory (H7); a symlinked directory
  has one scope on every OS.
- `memory import` registers a bare pre-v1.22 scope name as a legacy alias when
  it equals the importing directory's folder name.
- The legacy-name alias also applies to `memory failure list`, task context
  (`memory context --path/--command/--symbol`, REST and MCP) and `memory
  export --scope`.
- `memory forget` accepts the short IDs that `list` and `search` print.

**Watch and server**

- Server watch syncs the index; a changed file is attributed to every watched
  index whose directory contains it, with the ignore rules of a CLI build.
  The index directory and gleann data directories are never watched.
- `DELETE /api/indexes/{name}` unwatches the index, cancels and waits for a
  running sync and answers 409 while a build or sync holds the lock. A refused
  delete keeps the watch.
- A renamed or removed directory under a watched root drops its passages
  (`index watch` and the server watch).
- A busy index no longer holds a background worker; a timer resubmits the
  batch.
- Background task history keeps the last progress message of a successful
  task.
- `/v1/models` explains the `gleann/` entry; index entries have a description.
- The reranker warning is printed once per process.

**Filters**

- `ext` has one definition (extension of the base name, lower-cased; `1.10`
  has the extension `.10`).
- `--filter 'field exists'` keeps passages that have the field.
- `--filter` values are lossless: `version eq 1.10` compares the string
  `1.10`; `gt/gte/lt/lte` need a number, `in/nin` a JSON array; NaN, Inf and
  `null` for `in/nin` are refused on REST, MCP and CLI. `gleann search`
  validates `--filter` before starting a backend.
- REST `exists` without a value means true.

**Setup and models**

- One Ollama host rule everywhere: `serve` auto-setup, `setup`, `doctor`, the
  config check and `multimodal` used to ignore `OLLAMA_HOST`.
- Model downloads are safe to run concurrently (unique temp file, size and
  sha256 verified, atomic rename).
- The ms-marco pooler entry can carry a checksum.
- The "no Go module" warning is printed once, not on every sync.

**Read-only commands and graph**

- `gleann doctor`, `gleann index info` and `gleann graph stats` open the
  index read-only and run no migrations.
- `graph stats` counts edges by confidence across every edge kind;
  `graph map` and `graph report` state what they count; `graph explain`
  counts add up and test callers are marked.

**Windows and macOS**

- Canonical scope paths on every OS, junction and reparse-point refusal,
  case-insensitive legacy aliases on Windows, safe export file names (see the
  Windows notes).

**Tests and CI**

- The CLI end-to-end test builds its own binary, fails instead of skipping
  when the build fails, and isolates `HOME` and the `GLEANN_*` directories
  per test.

## Plugin releases

- **gleann-plugin-docs v1.5.6**
  - Added: per-class conversion limits (heavy and light work have separate
    slots, queues and `Retry-After`; `GLEANN_DOCS_MAX_HEAVY`,
    `GLEANN_DOCS_HEAVY_QUEUE`, `GLEANN_DOCS_MAX_LIGHT`,
    `GLEANN_DOCS_LIGHT_QUEUE`); bounded admission (429 when a class has no
    free ticket, upload idle and total timeouts); `Retry-After` on every 503
    and 429; queued requests are refused with 503 on shutdown.
  - Fixed: HTML nested deeper than 512 elements answers 422; DOCX heading
    levels beyond six clamp to `######`; the conversion budgets are
    concurrency-safe; errors no longer reveal temporary paths; a broken,
    truncated or encrypted PDF answers 422 instead of 500.
- **gleann-plugin-sound v1.2.1**
  - Security: `/convert` staging moved to a per-user directory that is
    checked before use, and the startup sweep no longer follows symlinks.
  - Fixed: `/live` sends the unrefined text with `"refined": false` when the
    refiner fails; a refiner sidecar is supervised and restarted with
    back-off, and `/convert` answers 503 with `Retry-After` while it is down;
    shutdown finishes inside the host's stop grace; `/health` reports
    `restarting` and `down` correctly.

## Known limitations

- Windows is exercised through CI, not by hand.
- A gemma index built before this release has no prompt prefixes until rebuilt.
