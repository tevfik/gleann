# gleann v1.8.7

`gleann chat` now runs on the agenttui interface by default, and you can choose
which indexes and tags it searches while you chat.

## Highlights

- **New default chat interface.** Cancellable streaming (Esc), collapsible
  reasoning, source cards under each answer, a slash-command popup and
  `@file` / `@symbol` completion. `--classic` (or `GLEANN_CHAT_UI=classic`) brings
  back the old interface; `--modular` is still accepted and does nothing.
- **Pick indexes and tags in the chat.** `/index` opens a panel with a switch per
  index and per tag (`gleann index tag`); ticking a tag selects every index that
  carries it. Also `/index a,b`, `/index #tag`, `/index add|remove <name>`,
  `/index info`. The selection really changes what is retrieved. In earlier
  versions `/index <name>` only changed the label in the chat.
- **Retrieval sidebar.** Lists every index with its passage count, a graph marker
  and tags, which ones are searched, and how many passages of the last answer
  came from each. Sources of a multi-index answer name their index.
- **`@symbol` over several indexes.** Type `@` plus part of a symbol name to attach
  its definition from the code graph; with several indexes the first one that
  has a graph is used.
- **Settings panel** (`/settings`, Ctrl+S) with sliders for temperature, repeat
  penalty, max tokens and top-k, reranker, role and system prompt.
- **CLI and server port flags.** `gleann serve` now supports `--port` and `-p <port>`
  shorthands (in addition to `--addr`), bare port numbers, and provides `--help` output.
- **Real context window.** The chat asks the provider for the model's window
  (Ollama `num_ctx` sent, Modelfile `num_ctx`, loaded model; OpenAI-compatible
  `/models` fields) instead of guessing from the model name. When the provider
  does not say, only used tokens are shown. `GLEANN_CONTEXT_TOKENS` overrides.
- `/forget` asks for confirmation before deleting memories.

## Upgrading

- The `ext/eif-runtime` submodule is now `ext/bitllm.c`. After pulling, run
  `git submodule update --init --recursive`.
- With Ollama, a model that is not told a `num_ctx` runs with the server default
  (often 4096 tokens), which can be smaller than what top-k retrieval sends. The
  context gauge now shows the real value; raise it with `GLEANN_OLLAMA_NUM_CTX`.

## Verification

`go test -race` over the whole module (as CI runs it) and with `-tags treesitter`
for `cmd`, `internal/tui`, `pkg/gleann` and `internal/server`. The chat was also
run end to end in a terminal against a real code-graph index and a local
`qwen3.5:9b`: `@symbol` completion, retrieval with sources, `/index` by name, tag
and multi-index, and the `/forget` confirmation.
